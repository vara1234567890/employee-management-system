Each module class contains its own Swing JFrame and attaches ActionListeners to buttons. On user interaction, the module calls DBConnection to get a live JDBC connection, then executes PreparedStatements for safe, parameterized SQL queries against the MySQL database. Results are displayed back in the Swing UI.

Key Features

SQL Injection Safe

All queries use PreparedStatements to prevent injection attacks.

Full CRUD

Create, Read, Update, and Delete operations fully implemented.

Desktop GUI

Native Java Swing interface — no browser or web server needed.

MySQL Persistence

All records stored and retrieved from a relational database.

Modular Design

Each operation is a self-contained class — easy to extend.

Centralized DB Layer

DBConnection class reused across all modules — DRY principle.
